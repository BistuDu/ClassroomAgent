## 失败与恢复

| 场景 | 预期结果与恢复入口 |
| --- | --- |
| 配置缺失 | 能力卡显示准确缺项，无密钥值；生成失败保留方案/草稿。填好 `.env`、重启后发送继续请求 |
| 同批调用 ask_user 后再写入 | 成功询问持久化等待锁；Pi 顺序钩子阻止后续调用，混合批次 finishTurn 结束本轮。只有关联当前问题的真实回答解除锁 |
| 生成内容不合法或截断 | 不保存半页；错误包含校验位置，读取最新版本并修正 |
| 运行中取消或重启 | 保存成果保留，旧运行禁止后续写入。待回答问题保留；新请求读取真实缺口，不自答问题 |
| 重复消息/工具请求/SSE | 同一标识复用已知结果，不重复保存；重连从序号补发并按序号去重，其他会话事件不混入 |
| 版本冲突/锚点重复 | 拒绝整次修改，原文档不变；重新读取 revision，使用唯一锚点 |
| 讲稿/音色在合成期间改变 | 旧签名不能覆盖新稿。补合成受影响段落；有效签名可复用 |
| 音频不存在、过期或播放失败 | 当前播放步骤停止并提示；不能把缺音频当作已讲解完毕，可补全后重试 |
| 无效幻灯片或实验目标 | 保存时拒绝悬空引用；实际 DOM 缺失或 ACK/ERROR/超时则检查失败与播放暂停 |
| 实验手动输入只改控件不更新模型 | observe/状态检查报告具体控件和输入，不以可见控件代替真实交互通过 |
| 窄屏主要控件不可达 | 375×812 检查报告溢出；修正布局后重新检查。其他视口列为未覆盖 |
| 旧截图提交视觉通过 | snapshot 指纹或默认视口不匹配时拒绝；必须重新截图并检查 |
| 两轮修正后仍失败 | 保留草稿、问题和检查记录，课程不显示就绪；助手报告未解决项或询问用户 |
| 公开 URL 指向内网、重定向内网、资源过大 | 读取被拒绝，资料无法改变执行权限；选择公开且受限大小的资料 |
| 实验尝试读取接口或跨实例发消息 | sandbox/CSP/业务来源检查阻止接口访问；宿主忽略非当前窗口、实例或请求 ID 的消息 |

视觉判断只覆盖记录的截图与状态。对数学/物理模型的科学正确性，应对照引用和已知公式人工核对；本项目没有执行官方教学效果评测。
