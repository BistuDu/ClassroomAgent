# 语音故障修复与验证

日期：2026-10-05。修改范围：OpenMAIC-python。

## 已确认的故障

最初课程 revision 15 有 26 段 speech，全部没有音频绑定，数据库没有音频媒体。十个百炼合成任务已经返回 WAV 地址，网页配音任务和 Agent 工具均在下载时报告 `MEDIA_URL_RESTRICTED`。

返回主机是 `dashscope-result-bj.oss-cn-beijing.aliyuncs.com`，在原有官方域名匹配范围内；实际拒绝的原因是 URL 使用 HTTP，下载函数只允许 HTTPS。阿里官方 HTTP API 文档也使用这种返回格式。现在先验证官方主机、无凭证、标准端口，再仅改变协议为 HTTPS；路径与签名查询串保持原样。重定向、DNS、TLS 和大小限制继续生效。

真实验证还观察到 Qwen WAV 的 RIFF/data 长度为流式占位值（约 2 GiB），实际样本只有数百 KB。新增完整性校验最初因此拒绝样本，现已修正：仅对识别出的占位头按完整下载体重写长度，再读取 PCM 和真实时长；常规 WAV 截断及无效文件仍被拒绝。所有保存输出使用标准 WAV 头。

另外修复：网页指定段“重新配音”现在传递显式 force，不会继续复用过期下载任务；整页“补齐”继续复用有效媒体。试听独占标识防止旧结束事件停止新声音，加载失败能够显示错误。最后一页播完后再播放会从首个动作重新开始，无讲稿的页给出明确提示。
