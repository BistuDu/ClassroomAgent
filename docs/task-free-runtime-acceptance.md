# 移除任务登记工具验收

变更：remove-set-course-tasks-tool。日期：2026-10-11。

## 实现

- 新工具契约共有 20 个工具，不包含任务登记工具。Agent 读取稳定课程/页面 ID 和版本后直接执行业务工具。旧名称仅保留迁移拒绝和历史缓存只读适配。
- RunContext 保存当前用户、对话、来源消息、已核实课程/页面及版本；每次写入仍执行归属、版本、关系、锁与实际影响范围校验。目录读取和首次写入不自动要求完善整课。
- OperationRecord 保存参数哈希、输入/输出版本、紧凑结果、错误和实际影响，关联真实 SDK start/end 事件。相同请求重放返回原回执，参数变化拒绝，缺完整回执不自动重复付费请求。
- CourseStatus 从实际课件、讲稿、音频文件与签名、程序/视觉报告及指纹计算。局部执行结算报告本轮新增失效和未解决失败，同时单独显示整课状态。
- 旧任务字段和历史事件只读保留。生成页面/动作结果为摘要，完整源码按需 read_stage 回读；SDK 详情仍保留完整结构化调用参数。

## 未进行与部署边界

未进行真实浏览器交互验收：制作卡片展开、SSE 断线恢复、历史工具展示和真实音频播放尚未在浏览器核验。此前本地站点访问受保存权限限制，本轮未尝试绕过；Node 结构验证和接口验证不等价于浏览器验收。任务 4.3 明确允许记录此缺项。

本轮没有重启活动服务，没有改写现有课程或实时数据库，也没有重新生成生产媒体。上线需要在合适时点重启后端以加载新 Python 实现；当前运行服务是否已经加载新版本未确认。历史迁移文档与历史验收保留，新验证只写临时副本与独立验收文件。
