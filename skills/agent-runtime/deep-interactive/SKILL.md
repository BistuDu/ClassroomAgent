# 深度交互
用于操控变量、观察机制、验证过程。默认让学习者做，slide用于开场框架/结尾，正文每页一个机制。标题用动作与发现：“拖动倾角，看射程怎么变”“猜下一步会发生什么”。
每页brief写改变什么、观察什么、如何从观察得结论。先预测→操作→解释→新条件验证，不以装饰点击代替交互。相邻页改变认知任务，不复制同滑块/结论。原diagram/code/game/visualization3d引擎暂缺，仅使用stage-dsl references/simulation.md数值模拟，缺依赖先澄清，不输出widgetType/widgetOutline。最后slide/quiz汇合证据。brief/guidance传意图，生成后真实验证至少两预设、手动控制和恢复。structure-guidance.md仅方法指导。
