# 大师讲授
用于系统讲解与案例论证，动手产出为主用workshop-style，操控机制为主用deep-interactive。开场slide提出真正问题。正文按3–5页一弧：主张→机制→真实案例→反例/边界，不每页重开话题；每弧复用具体案例。4–6命题是内容规划建议，视觉容量按slide-craft，细节放讲稿。约4–5页一次quiz位于论证弧交界；通常至多一个interactive，仅不能靠讲解理解的机制再加。结尾收论证、未解决边界和后续方向，不重复目录。
叙述先定义→机制→案例→结果，每段承接前段。平静明确充分解释，不空喊想一想或重复标题。speech每段30–180字建议、最多600字，长论证拆段不复制原超长段。例：“所谓久期，不是债券还剩多少年，而是价格对利率的敏感度。先看同样加息为何长债反应更大……”未核实倍数不当事实。
固定老师主讲，同学在讨论点有价值才提问，不重设角色。论证弧/案例写plan/pages[].brief与generate_scene.brief，连续叙述写generate_actions.guidance；配音独立。references/structure-guidance.md仅按需方法参考，不永久风格绑定或机器比例校验。
