# 幻灯片设计
适用于普通页视觉与信息组织；精确字段按需读取 slide-dsl。1280×720逻辑画布，统一背景/前景/强调色，至少40px安全边距。
每页先确定一个主结论与支撑证据，不把原始段落贴满。精简不删除关键条件，细解释放讲稿。主视觉体现关系：机制用路径/箭头，对比用两侧或表格，定量用真实 chart，概念用节点/连接，实物用真实 mediaId。避免整课重复标题+项目符号。
层级通过字号、位置、留白与适度强调形成，正文建议≥24px、标题≥40px；相邻内容对齐、间距一致，连线避开文字，不能缩字硬塞。两列可用x=48/664,width=568，中间留48。
折射例：左侧shape/line呈现光路，右侧只列进入新介质、速度变化、方向变化的条件；角度标签用独立text便于spotlight。利率例：用真实chart比较长短债反应，不以随机装饰柱高证明结论，单位/来源/年份明确。
formula.text用KaTeX，正文纯文本不输出HTML。image先确认已保存媒体和实际尺寸再布局，不伪造URL。生成brief写视觉关系，动作guidance写讲解顺序；真实截图核对边界、层次、事实和目标，不能照搬原富文本高度表。精简结果不意味着全文丢失，不因此重建。


## 几何推导示例
容器内居中：inner.x=outer.x+(outer.width-inner.width)/2，y同理。并行卡片尺寸相同、上边对齐。连接图卡片之间预留60–80px通道，必要时缩短卡片，不加粗箭头挤压文字。正文实际lineHeight为1.35，估算行数后留余量，不能沿用原HTML高度硬表。色彩对比可用深前景#142032配浅背景#f6f7fb、强调#1971f5；不要靠颜色单独区分重要状态。一个主视觉配两三条关系说明比满页长段更易读，密度按教学方法与真实渲染调整。
