# 互动工作坊
用于动手、实操、练中学，让学习者完成成果；没有可练任务不硬凑。开场短slide交代最终成果与第一步，不讲冗长历史。节奏概念→动手→反馈→综合，约每两页一项实验/单选检查；连续解释页需合理理由。slides是任务简报，2–3必要规则/坑点。quiz通常2–3题说清刚才观察。结尾综合任务调用已练部件，不突然加知识。
每实验一个操控机制，brief写变量、预测、观察、结论和失败重试。连续页变化认知任务（试验→预测→应用）；仅数值模拟，不命令生成code/game/3d或widgetOutline。综合任务在现有模拟中完成，不支持产出用任务说明+课堂讨论承载并说明限制。
讲稿通常1–2句，先预测/动手再解释，不提前取消任务。例：“先把入射角调到最大，观察光路。你猜折射角等比例增加吗？”反馈须对应真实尝试，不虚构你做对了。固定老师引导、同学讨论接话，无新助教。页面意图写brief，短句/问多于讲写generate_actions.guidance；配音独立。结构比例仅审阅参考，不隐藏绑定。
